Bandit Scan Output

$ bandit -r exp8_vuln_sample.py Test results: B403 - pickle import B404 - subprocess import B301 - pickle.load B602 - subprocess shell=True B324 - MD5 usage B105 - hard-coded password Undefined : 0 Low : 3 Medium : 1 High : 2

Security Remediation

B301 — Unsafe Deserialization

Unsafe pickle deserialization was removed and replaced with JSON loading.

B602 — Command Injection Risk

shell=True was removed and subprocess execution uses shell=False.

B324 — Weak Cryptography

MD5 was replaced with the stronger SHA-256 hashing algorithm.

B105 — Hard-coded Secret

The hard-coded password was removed and replaced with an environment variable.
